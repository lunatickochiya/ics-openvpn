# WireGuard 使用说明

## 导入配置

1. 在主界面点击导入，选择 `.conf` 文件，或直接新建/编辑 WireGuard 配置。
2. 配置内容就是标准 wg-quick 格式，至少包含 `[Interface]` 和 `[Peer]`：

```ini
[Interface]
PrivateKey = ...
Address = 10.66.66.2/24
DNS = 10.66.66.1

[Peer]
PublicKey = ...
Endpoint = vpn.example.com:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
```

3. 保存后点击配置即可连接。首次连接需要授予 VPN 权限。

## 路由模式

WireGuard 使用 `AllowedIPs` 同时决定“哪些流量进入隧道”和“安装哪些系统路由”。编辑器提供三种模式：

| 模式 | 行为 | 适用场景 |
| --- | --- | --- |
| 使用配置中的 AllowedIPs（默认） | 完全按配置文件中的 `AllowedIPs` 安装路由 | 全隧道或已写好分流网段 |
| 不覆盖默认路由 | 移除 `0.0.0.0/0` 和 `::/0`，保留配置中的其他网段 | 不想接管默认路由，只访问配置中列出的远端/局域网网段 |
| 自定义路由 | 忽略配置中的 `AllowedIPs`，只使用编辑器中填写的 CIDR | 只让指定网段走 VPN |

自定义路由示例：

```text
192.168.50.0/24, 10.10.0.0/16
```

说明：

- “不覆盖默认路由”只移除默认路由；如果配置里只有 `0.0.0.0/0`，连接后不会接管任何流量，此时应改用“自定义路由”。
- 自定义路由会应用到所有 `[Peer]`。多 Peer 的复杂分流建议直接编辑配置并选择“使用配置中的 AllowedIPs”。
- 自定义路由填写错误时，保存按钮会提示具体网段格式错误。

## 指定应用使用 VPN

在 WireGuard 配置编辑器中点击“选择使用 VPN 的应用”：

- 默认是“除了被选择的之外，VPN 将用于所有应用程序”。
- 切换开关后可以改为“VPN 仅用于选择的应用程序”，然后勾选需要走 VPN 的应用。
- 如果选择“仅用于选择的应用程序”但没有勾选任何应用，配置检查会阻止连接。

也可以直接在配置文件中写入（包名以逗号分隔）：

```ini
[Interface]
PrivateKey = ...
Address = 10.66.66.2/24
IncludedApplications = com.example.browser, com.example.player
```

`ExcludedApplications` 的语义相反，用于排除指定应用。两者不能同时使用。

## 常见问题

- **连接成功但无法上网**：检查路由模式。若使用“自定义路由”，确认目标网段包含需要访问的地址；若使用“不覆盖默认路由”，确认配置中存在非 `0.0.0.0/0` 的网段。
- **只有部分应用走 VPN**：检查“选择使用 VPN 的应用”页面中的开关和勾选项。
- **DNS 不生效**：在 `[Interface]` 中设置 `DNS = ...`；Android 会把该 DNS 应用到 VPN 网络。
- **远端地址解析失败**：确认设备可以解析 `Endpoint` 中的域名，或直接填写 IP 地址。
- WireGuard 配置和私钥保存在应用私有存储中，并受应用配置加密选项保护。
